# AI谱 · 用户支持

AI谱是一款面向 iPhone 和 iPad 的端侧 AI 模型评测应用，支持大语言模型、ASR 语音识别模型评测，以及设备性能测试。

本仓库用于用户支持、问题反馈和功能建议，不包含 App 源代码。

## 问题反馈

请通过 [GitHub Issues](https://github.com/lawson-source/AI-Spectrum-Support/issues) 提交问题或建议。提交前可先搜索已有反馈。

为方便排查，请尽量提供：

- App 版本、iPhone 或 iPad 型号及系统版本。
- 使用的模型名称、操作步骤、预期结果与实际结果。
- 已去除个人信息的截图或错误提示。

Issues 对所有人公开。请勿上传密码、访问令牌、Apple 账户信息、原始录音、敏感提示词或其他私人数据。分享诊断包前请先检查内容并删除敏感信息。

## 常见问题

- **首次使用模型需要联网吗？** 首次使用通常需要下载模型文件；支持本地推理的模型下载完成后可在设备上运行。
- **模型加载失败或内存不足怎么办？** 尝试更小的模型或更短的输入，并确认设备有足够的可用存储空间。
- **如何导入音频？** 在 ASR 页面导入音频文件，或在语音备忘录中通过“共享”选择 AI谱。
- **AI 输出是否一定准确？** 模型输出可能有误，评测分数仅用于参考，不应替代专业判断。

## Support

For bug reports and feature requests, please open an issue and include your app version, device model, iOS/iPadOS version, model name, and reproduction steps. Issues are public; do not include personal or sensitive data.
